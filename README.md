# GTA3 资源工程

## 使用方法

资源目录是工程中的：

```text
gamefiles/
```

将本工程的游戏资源部署到
`/data/gta3/`
确认资源目录中至少有：

```text
/apps/re3/re3
/data/gta3/models/gta3.img
/data/gta3/models/gta3.dir
/data/gta3/data/main.scm
/data/gta3/anim/
/data/gta3/TEXT/
```
